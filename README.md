# UrbanLink

UrbanLink e uma proposta de solucao front-end para a SoulUp, criada para incentivar o uso do transporte publico por meio de pontos, vouchers e metricas de impacto ambiental. A plataforma simula uma jornada em que o usuario valida trajetos sustentaveis, acumula Creditos Ecoa e acompanha beneficios ligados a mobilidade urbana.

## Objetivo

O projeto resolve o problema 2 do challenge da SoulUp: transformar mobilidade sustentavel em uma experiencia recompensadora, acessivel e mensuravel. A solucao combina:

- validacao de trajetos por geolocalizacao e registro fotografico;
- acumulacao de Creditos Ecoa;
- troca de pontos por vouchers ou beneficios de transporte;
- visualizacao de impacto ambiental;
- possibilidade de parcerias ESG para financiar recompensas.

## Paginas

- `index.html`: apresentacao da proposta, jornada do usuario, CTA, simulacao de creditos e recursos antifraude.
- `pages/quemSomos.html`: integrantes com nome, foto, RM, turma, GitHub e LinkedIn.
- `pages/sobre.html`: contexto do problema, solucao, dados de mercado, roadmap e modelo de negocio.
- `pages/faq.html`: perguntas frequentes sobre pontos, vouchers, validacao e uso da solucao.
- `pages/contato.html`: formulario com validacao em JavaScript e feedback visual ao usuario.

## Funcionalidades JavaScript

- menu hamburguer responsivo;
- carrossel/tabs na secao "Como funciona";
- modal de integrantes;
- timeline interativa na pagina Sobre;
- accordion de FAQ;
- validacao de formulario com mensagens de erro e sucesso.
